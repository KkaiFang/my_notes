# 能否自动更新

这是一篇用来验证「新增 md 是否会自动出现在网站上」的测试文章。

## 为什么新加的 md 没有出现在网站

1. 文件没有被提交或推送：线上站点只根据 GitHub 仓库 `main` 分支构建，本地新增的文件必须
   `git add` / `git commit` / `git push` 之后才会被构建。
2. 文章缺少一级标题：没有 front matter `title`、也没有 `# 标题` 时，导航条目没有名字，
   旧配置下就不会显示。
3. 文章所在的目录没有被放进导航：`docs/.pages` 里的顶层 Tab 和各级目录的 `.pages` 决定
   哪些内容会出现在站点里，不在其中的文件不会被链接到。

## 现在的新增流程

导航由 awesome-pages 插件按目录自动生成，新增文章只需要：

1. 在目标目录（如 `docs/develop/`）新建 md 文件；
2. 第一行写一个一级标题，例如 `# 文章标题`；
3. 提交并推送到 `main`。

推送后 GitHub Actions 会自动构建并发布，文章会出现在对应分区的侧边栏里。
如需控制顺序或单独命名，在目录的 `.pages` 文件里加一行即可。
